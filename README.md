Задания находятся в разных папках.

До начала работы убедитесь, что у вас установлены node.js и npm.

Для первого задания перейдите в папку task_1 и запустите скрипт.

-------------------

```shell
cd task_1/
node test_1.js
```

-------------------

Для второго задания
-------------------

Перейти в папку task_2

```shell
cd task_2/
```

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запустите тест с помощью команды:
```shell
npx playwright test
```
